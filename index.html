About this program

Munnin is a personal task and reminder application operated by Corey Artim in Dayton, Ohio. The application sends SMS message reminders to a single recipient — the operator — about tasks and events the operator has scheduled. It is operated for personal use only and is not offered as a commercial service to the public.

This page describes how SMS opt-in works, what messages the operator will receive, and how to opt out at any time.

SMS Opt-In

The operator opts in to receive SMS messages by entering their own mobile phone number into the application's Settings screen and explicitly enabling SMS reminders. Below is a representation of the opt-in interface within the application:

STOP and HELP

The operator can opt out of receiving SMS messages at any time by replying STOP to any message. Once STOP is received, the Twilio platform will immediately stop sending further SMS messages to that number and respond with a confirmation. To resume messages later, the operator may reply START.

The operator can request help at any time by replying HELP, or by contacting the operator directly at cartim@yourlegalhelp.com.
